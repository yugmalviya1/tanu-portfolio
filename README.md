# 🎨 Tanishka Shrivastav — Graphic Design Portfolio

An editorial, high-voltage portfolio website showcasing the graphic design work, event branding, viral social media carousels, and visual identity projects of **Tanishka Shrivastav** (Lead Graphic Designer at LNCTE E-Cell & contributor to E-Cell IIT Bombay's National Entrepreneurship Challenge).

---

## ✨ Features & Highlights

- **Interactive 4-Slide Storytelling Carousel**: Complete interactive slide walkthrough of the viral Airbnb origin story project (*"They Couldn't Afford Rent..."*), designed for E-Cell IIT Bombay's NEC.
- **Event & Summit Branding Showcase**: Featuring high-impact works for LNCT Group's *E-Summit '25*, *Blockchain Blitz*, *Case Study Competition*, and *Stand-Up Comedy Night*.
- **Full-Screen Interactive Lightbox**: Detailed view of each project with design concepts, tools used, color palettes, and direct PDF download/preview links.
- **Category Filtering**: Seamless filter tabs for *All Projects*, *Event Posters*, *Storytelling & Carousels*, and *Teasers & Campaigns*.
- **Behind the Canvas (Color Lab)**: Interactive signature swatch palette with 1-click clipboard copy for designers and clients.
- **Project Brief Generator**: One-click brief sender routing directly to WhatsApp (`+91 76439 21187`) and Email (`tanishkashrivastav@gmail.com`).
- **Modern Glassmorphic Dark Aesthetic**: Built with modern CSS custom properties, backdrop blur, fluid typography (Syne & Plus Jakarta Sans), and smooth micro-animations.
- **100% Responsive & Zero External Framework Dependencies**: Blazing-fast performance using pure Vanilla HTML5, CSS3, and JavaScript.

## 🛠️ Technology Stack

- **HTML5**: Semantic tags, Open Graph meta tags, responsive viewport configuration.
- **CSS3 (Vanilla)**: CSS Grid, Flexbox, CSS Variables, glassmorphism (`backdrop-filter`), keyframe animations.
- **JavaScript (ES6+)**: Custom carousel slider, modal dialogs, category filtering, clipboard API, and query builders.
- **PyMuPDF & Pillow**: Pre-rendered ultra-high-resolution image assets and web-optimized WebP thumbnails.

## 🚀 How to Run Locally

1. Clone or open the project folder:
   ```bash
   git clone https://github.com/yugmalviya1/tanu-portfolio.git
   cd tanu-portfolio
   ```

2. Start a local server:
   ```bash
   # Using Python
   python -m http.server 8080

   # Or using Node (npx)
   npx serve .
   ```

3. Open your browser at `http://localhost:8080`.
